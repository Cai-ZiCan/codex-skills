# 科研工作规范与技能

本仓库维护科研代码文档技能与通用科研、代码协作规范。

| 内容 | 入口 | 用途 |
| --- | --- | --- |
| scientific-code-documentation | [SKILL.md](skills/scientific-code-documentation/SKILL.md) | 科研代码分层 README、模块边界、公式与代码对应说明 |
| AGENTS.md | [工作规范](rules/AGENTS.md) | 任务范围、适度验证、目录治理、算法与模型文档、数据与输出规范 |

## 使用

将 `skills/scientific-code-documentation` 完整复制到 Codex 的技能目录。`rules/AGENTS.md` 可作为全局或项目工作规范的参考，按项目情况采用。
